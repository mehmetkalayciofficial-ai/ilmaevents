# İlma Events

Luxury event design — İstanbul × Dubai.
Marriage proposals, birthday surprises, and bespoke concepts.

## Stack
- Single `index.html` (static)
- Tailwind CSS (CDN)
- Cormorant Garamond + Manrope (Google Fonts)
- Lenis smooth scroll

## Local development
```bash
node serve.mjs
# http://localhost:3000
```

## Deploy
Hosted on Vercel — pushes to `main` auto-deploy.
